O FutClassics foi desenvolvido para proporcionar uma experiência interativa e educativa sobre o universo do futebol internacional. A plataforma reúne informações detalhadas sobre partidas, resultados, seleções, torneios e locais dos jogos, oferecendo aos usuários um acesso facilitado e intuitivo a esses dados.

O projeto foi concebido com foco na integração entre frontend, backend e banco de dados, garantindo robustez, funcionalidade e usabilidade.

Tecnologias Utilizadas
Frontend
React: Biblioteca utilizada para construção da interface de usuário, com foco na criação de componentes reutilizáveis e em uma navegação fluida.
Vite: Ferramenta de configuração utilizada para fornecer um ambiente de desenvolvimento ágil e eficiente.
As interfaces foram projetadas priorizando usabilidade, clareza na visualização de dados e integração intuitiva com o backend.
Backend
Node.js: Ambiente utilizado para criar a lógica do servidor e gerenciar a aplicação backend.
Drizzle ORM: Framework escolhido pela sua flexibilidade e facilidade de integração com o banco de dados.
O backend foi responsável por implementar as rotas, os controladores e toda a lógica necessária para conectar o frontend ao banco de dados.
Base de Dados
O sistema utiliza um conjunto de dados detalhado sobre partidas de futebol internacionais. Este dataset foi selecionado pela sua riqueza e diversidade, permitindo a exploração de diferentes aspectos de modelagem e manipulação de informações. O SGBD utilizado foi o MYSQL.

Objetivos
Consolidar conhecimentos práticos adquiridos em disciplinas relacionadas a bancos de dados.
Explorar a importância de um banco de dados bem projetado para a tomada de decisões em diferentes contextos.
Evidenciar o papel central de informações organizadas no mundo moderno, especialmente no contexto do futebol.
O FutClassics é uma demonstração prática de como a integração entre tecnologias modernas pode facilitar o acesso a dados complexos, promovendo aprendizado e interação em um tema globalmente relevante como o futebol.
